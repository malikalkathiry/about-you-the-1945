# About You - The 1975

Web lyric visualizer for "About You" by The 1975 using vanilla HTML, CSS, and JavaScript.

## Features

- Word-by-word synced lyrics (`assets/audio/about-you-v2.mp3`)
- Looping background video (`assets/video/About-you-vid.mp4`) with grain and vignette
- Canvas cursor trail (`js/dust.js`)

## Structure

```text
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── main.js
│   └── dust.js
└── assets/
    ├── audio/
    └── video/
```

## Run Locally

```bash
python -m http.server 8000
```

Open `http://localhost:8000` in your browser.
